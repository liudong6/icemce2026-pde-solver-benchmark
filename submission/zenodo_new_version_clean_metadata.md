This archive contains the manuscript, source code, raw CSV evidence, generated figures and tables, environment requirements, and prior verification records for a reproducible finite-difference benchmark of solver selection and CPU/GPU stencil scaling in heat-conduction simulation. Version v6 publishes the revised author-to-reviewer response in a two-page Word document and a matching Markdown source, and updates all delivery packages and manifests. The response addresses face averaging and the interpretation of distinct timing protocols. The manuscript, scientific code, raw measurements and numerical results are unchanged from version v5 (10.5281/zenodo.22874266). No new numerical experiments were performed for v6. Citations to v5 within the unchanged manuscript and the response identify the experimental evidence already archived there. Version v6 is identified by 10.5281/zenodo.22908710. The retained evidence includes the original benchmark, controlled matched-field and candidate-solver audits, and the 378-solve paired callback calibration from v5. Earlier published versions are preserved. The historical repository ZIP filename does not indicate its current contents; the included release note and manifests identify this version.
